Bad Apple Box

An ESP32 + OLED build that plays the Bad Apple!! video from Touhou.

Overview

This project is a fun embedded challenge: take a well-known high-contrast video (“Bad Apple!!”) and get it to play smoothly on a small OLED display using an ESP32.

The goal was to explore the full pipeline—preprocessing frames, fitting them to the display, storage/streaming constraints, and keeping playback timing stable on embedded hardware.

Tech

  • Microcontroller: ESP32
  • Display: OLED
  • Focus: frame conversion + storage + playback timing
